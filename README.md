# Morrow Market

Next.js App Router와 Node.js Route Handlers, MySQL로 만든 한국어 쇼핑몰 데모입니다. MySQL을 연결하지 않아도 상품 탐색, 브라우저 기반 회원가입/로그인, 장바구니, 테스트 주문과 관리자 화면을 둘러볼 수 있습니다. MySQL을 설정하면 계정·상품·주문·회원·방문 통계를 서버에 저장합니다.

## 시작하기

필요 환경: Node.js 20 이상, MySQL 8 이상.

```powershell
npm install
Copy-Item .env.example .env
```

`.env`의 `DB_PASSWORD`를 로컬 MySQL 비밀번호로 수정한 다음 스키마와 데모 데이터를 준비합니다.

```powershell
npm run db:init
npm run db:seed
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다. 로컬 MySQL을 준비하지 않은 경우 `npm run dev`만 실행해도 로컬 데모 모드로 사용할 수 있습니다.

## 데모 계정

- 관리자: `admin` / `admin1234`
- 고객: 화면의 회원가입에서 테스트 계정을 생성

테스트 결제는 승인된 것처럼 주문을 생성하지만 카드사나 결제 대행사에 연결되지 않으며 실제 금액이 청구되지 않습니다. 카드 번호를 입력받지도 않습니다.

## 기능

- 상품 검색, 카테고리 필터, 가격 정렬 및 상품 옵션 선택
- 장바구니, 배송 정보 입력, 테스트 카드/간편 결제, 재고 차감, 포인트 적립
- 회원 주문·배송 조회, 포인트·프로필 확인 및 정보 수정
- 관리자 상품 등록·수정·삭제·품절·재고 관리
- 주문 배송 상태와 회원 등급 관리, 일별·월별 매출 및 방문자 통계
- 관리자 전용 API는 서버 세션의 `admin` 역할을 확인

로컬 데모 모드의 데이터는 브라우저 `localStorage`에 저장됩니다. MySQL 모드의 로그인 세션은 HTTP-only 쿠키를 사용합니다.

## 주의

이 프로젝트는 로컬 테스트 전용입니다. 기본 관리자 비밀번호를 배포 환경에서 사용하지 말고, 공개 서비스에는 CSRF 방어, 요청 제한, 주소 검증, 보안 비밀 관리와 실제 결제 사업자의 검증된 통합을 추가해야 합니다. 저장소에는 Docker 및 Terraform 배포 설정이 포함되지 않습니다. 기본 상품 이미지는 Unsplash 원격 이미지를 사용합니다.
